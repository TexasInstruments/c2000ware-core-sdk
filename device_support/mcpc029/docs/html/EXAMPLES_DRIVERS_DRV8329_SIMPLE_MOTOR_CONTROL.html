Introduction

This example shows a simple implementation of 3-phase motor control. SysConfig is used to configure the DRV8329 gate driver and the MCPWM module. The MCPWM module is set up to generate 3-phase PWM signals that are open-loop sine-modulated to drive the DRV8329.

myDRV0(DRV8329) is configured over SPI to:

  • Clear any existing faults (CLRFLT)
  • Set the VDS level selection to 2.00V

myMCPWM0(MCPWM1) is configured to:

  • Generate 3-phase PWM (PWM1A/B, PWM2A/B, PWM3A/B) in Up-Down Count mode
  • Apply deadband on the rising and falling edges of all outputs
  • Trigger an interrupt (ET1) on every "Counter = Period" event

In the MCPWM ISR, the phase angle (theta) is incremented and the three sinusoidal duty cycles (120 degrees apart) are computed and written to the CMPA shadow registers of PWM1A, PWM2A, and PWM3A, producing a rotating 3-phase voltage waveform for open-loop motor control.

External Connections

Monitor GLA, GLB, GLC on the DRV8329 to see the 3-phase PWM signals. These gate driver outputs are driven by the following MCPWM/GPIO pins:

DRV8329 Pin MCPWM Output Phase Output
INHA PWM3A GLA
INLA PWM3B GLA
INHB PWM1A GLB
INLB PWM1B GLB
INHC PWM2A GLC
INLC PWM2B GLC

Watch Variables

  • interruptcounter - Counts the number of MCPWM interrupts
  • theta - Current phase angle in degrees
  • valA, valB, valC - Computed CMPA values for the three PWM phases

Steps to Run the Example

  • When using CCS projects to build, import the CCS project for the required combination and build it using the CCS project menu (see CCS Build Project).
  • Establish connections as mentioned in the External Connections section.
  • Launch a CCS debug session and run the executable, see Build, Load and Run
  • Using the watch variables, observe the 3-phase PWM waveforms.
